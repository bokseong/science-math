# 나의 별자리 찾기

교내 과학·수학 축전용 정적 웹 프로그램입니다. 생일을 입력하면 황도 12궁 별자리와 대표 별, 체험용 별빛 메시지를 보여 줍니다.

## 실행

`index.html`을 웹 브라우저에서 열면 됩니다. 결과 페이지는 Firestore의 `festivalHoroscopes/2026-10-14` 문서를 먼저 읽고, 연결에 실패하면 같은 내용의 내장 데이터를 사용합니다.

## 구성

- `index.html`: 생일 입력 페이지
- `result.html`: 별자리 결과 페이지
- `app.js`: 별자리 판정·결과 렌더링
- `horoscope-data.js`: 2026-10-14 API 운세의 오프라인 예비 데이터
- `firestore.rules`: 축전 운세 문서의 공개 읽기·클라이언트 쓰기 차단 규칙
- `style.css`: 반응형 화면 스타일
- `assets/zodiac-images/`: 실제 위치 기반 별자리 PNG 12장
- `assets/zodiac-overlays/`: 성도 뒤에 겹쳐지는 투명 별자리 상징 일러스트 12장

별자리 PNG는 J2000 좌표 기반 성도이며, 실제 관측 시의 방향·고도는 관측 조건에 따라 달라질 수 있습니다. 운세 기본 자료는 AstroWay 공개 일일 운세 API의 2026-10-14 응답을 바탕으로 정리했으며, 생년월일별 보조 문구는 난수가 아닌 고정 규칙으로 생성합니다. 운세는 과학적 예측이 아닌 축전 체험용 콘텐츠입니다.
