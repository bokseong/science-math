# 실제 위치 기반 별자리 PNG

12개 PNG는 2048 × 2048 픽셀입니다. 별자리 선이 화면 중앙을 크게 차지하도록, 별자리의 실제 J2000 적경·적위 범위를 정사각형 성도로 투영했습니다. 실제 각도 비율을 유지하므로, 원래 길쭉한 별자리는 빈 공간이 일부 남을 수 있습니다.

별 위치는 XHIP Extended Hipparcos Compilation(VizieR V/137D), 딥스카이는 Messier catalog와 Saguaro Astronomy Club Database 8.1의 밝은 대표 대상을 사용했습니다. 별자리 선은 BSD-3-Clause 라이선스의 [d3-celestial](https://github.com/ofrohn/d3-celestial) GeoJSON을 사용했습니다.

성도에는 시야 안의 메시에 및 밝은 DSO를 겉보기등급 순으로 최대 12개 표시합니다. 실제 관측 시 보이는 방향·고도는 날짜·시간·관측 장소에 따라 달라집니다.
